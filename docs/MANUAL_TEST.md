# 人工测试清单（v0.8）

包测试和两端构建都已自动验证。下面这些项目需要真实的麦克风、设备或云端账号。

## 准备

```bash
python3 scripts/generate_xcodeproj.py
xcodebuild -project Yuyin.xcodeproj -scheme Yuyin-macOS -configuration Debug \
  -derivedDataPath build/DerivedData CODE_SIGNING_ALLOWED=NO build
open build/DerivedData/Build/Products/Debug/Yuyin.app
```

## 会议软件 / 网页 / 其他 App（macOS）

- [ ] 音源选「系统声音」，在浏览器里播放一段中文视频 → 能实时转写；首次使用时 macOS 请求「录制系统音频」权限
- [ ] 腾讯会议（或飞书、钉钉、Zoom）通话中选「会议」并戴耳机 → 自己和对方的话都能转写，说话人被区分开
- [ ] 外放（不戴耳机）时选「会议」→ 对方的话不会被重复识别两遍（回声消除）
- [ ] 「指定应用」选择会议软件 → 只录该软件的声音；该软件没有发声时给出提示
- [ ] 拒绝系统音频权限后录音 → 约 8 秒后提示检查权限

## 多人识别与命名

- [ ] 下载「说话人声纹」后，两人轮流说话，每句定稿后带说话人标签
- [ ] 录音中点标签 → 输入「张三」保存 → 之前和之后的句子都显示「张三」
- [ ] 把「说话人 2」也命名为「张三」→ 两人合并
- [ ] 点某句的标签 →「这句其实是：」→ 选另一人或「新的说话人」
- [ ] 腾讯会议 / 访谈视频（两三个人轮流说，每人说几句完整的话）→ 不同的人得到不同的标签，同一个人前后一致；很短、分不清的句子不标（而不是标成别人）
- [ ] 旧版录的、几乎全是「说话人 1」的记录 → 更多 → 重新分析说话人 → 按人分开
- [ ] 已装旧版声纹模型时启动 → 自动下载新的「说话人声纹」（约 28 MB），无需操作
- [ ] 结束后记录、导出里都使用这些名字；记录页里右键（长按）名字可改名；「重新分析说话人」后名字保留

## 识别效果

- [ ] 用「系统声音」播放一段带背景音乐、几乎不停顿的中文视频 → 定稿内容与实时字幕一样完整，不会只剩零星几个字
- [ ] 播放英文视频 → 定稿是正常大小写、带标点的英文
- [ ] 中文里夹英文产品名（iPhone、Apple TV）→ 英文词基本正确
- [ ] 录音中点「展开」→ 卡片变大，显示完整的实时记录并自动滚动；点「收起」恢复两行

- [ ] 设置 → 模型 下载「Paraformer-large 中文」后，「中文标点」会自动一起下载；设置 → 识别 显示「纠错 Paraformer」
- [ ] 用笔记本麦克风正常音量说几句、中间停顿 → 每句话被单独切开，定稿带标点
- [ ] 敲一下桌子或点一下鼠标 → 不会出现乱码句
- [ ] 一个人连续说多句 → 都标为同一个说话人
- [ ] 说半句停一下（约 1 秒）再接着说完 → 是一句，不会拆成「他应该学的是」和「E技能」两句
- [ ] 一句话说完停顿约 1 秒再说下一句（每句都较长）→ 仍然分成两句
- [ ] 播放游戏解说或带音效的视频，「哎哟」「这波」这类短感叹不会变成日语
- [ ] 英文句子的标点是半角（", " 而不是「，」）

## 纯离线（核心路径）

- [ ] 设置 → 本机引擎显示「将使用：实时 Sherpa Zipformer · 纠错 …」
- [ ] 点「开始录音」后面板依次显示「正在加载模型…」→「正在聆听」，电平条随说话跳动，计时在走
- [ ] 说话时出现灰色实时文字；停顿约 0.7 s 后变为「纠错中」，再变为黑色定稿，右侧显示纠错引擎名
- [ ] 定稿带标点（SenseVoice / ANE）
- [ ] 风扇或空调噪声下静坐 30 s，不应持续冒出空句
- [ ] 连续说话超过 25 s 会被切成相邻的两句，衔接处不丢字
- [ ] 暂停后继续：暂停前那句已经定稿，暂停期间说的话不会被识别，计时不增加
- [ ] 刚说完最后一句马上点「结束」：显示「正在完成纠错…」，随后出现「已保存」卡片，最后一句也是定稿
- [ ] 断网后纯离线模式照常工作
